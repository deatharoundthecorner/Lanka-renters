# Coding Standards

## PHP

- MVC Architecture
- Use PDO Prepared Statements
- One responsibility per class
- Use meaningful names

## HTML

- HTML5 Semantic Elements
- Accessible Forms

## CSS

- CSS Variables
- Reusable Components
- Responsive Design

## JavaScript

- Vanilla JavaScript Only
- Modular Functions
- No External Libraries

## Database

- No SQL inside UI pages
- Database operations only inside models

## Security

- Validate Input
- Escape Output
- Session Authentication
